# day drinking

https://sebastianverjoustinsky-rgb.github.io/day-drinking/

Do you like day drinking? → Yes → the invitation → the details.
No → would you like to reconsider? → Yes goes back to the question, No ends it.

All the text lives in `index.html`, one `<section class="screen">` per screen.
The details are the `<dl>` in the `details` section. Edit, commit, push —
GitHub Pages redeploys in about a minute.
